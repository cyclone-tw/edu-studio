🔑 設定 API Key

首先需要設定 Google Gemini API Key 才能啟用 AI 大腦。

  1. 點擊右上角「🔑 AI 設定」按鈕
  2. 前往 Google AI Studio 申請 API Key（免費版即可）
  3. 複製 API Key 並貼上到輸入框
  4. 點擊「儲存」

🎨 三種生成模式

✨ AI 智慧生成

AI 自動生成：AI 會分析你的素材，自動設計簡報架構和重點。

現有大綱轉檔：保留你的大綱結構，只做格式轉換，文字內容一字不改。

📚 課文忠實模式

將課文原文完整呈現，一字不改、一字不漏，AI 只負責合理分頁。

📄 PDF 轉圖片

將 PDF 的每一頁轉換為高品質 PNG 圖片，方便插入簡報使用。

📗 如何使用 NotebookLM 製作簡報？

  1. 完成前三步驟後，點擊「下載 TXT」下載 YAML 施工圖
  2. 前往 Google NotebookLM 並建立新筆記本
  3. 將剛下載的 .txt 檔案上傳作為來源 (Source)
  4. 在 NotebookLM 中，指示 AI：「請根據這份 YAML 結構檔案，為我生成完整的簡報內容」
  5. NotebookLM 會自動分析並生成簡報內容
